# WallPulse Studio v3.0.0 — живые обои без лишней сложности (Windows 10 / 11 x64)

Портативное Windows-приложение для MP4/GIF/HTML/шейдерных обоев: C++17, Direct3D 11, Media Foundation, WASAPI, Direct2D. Основной интерфейс упрощён до пяти разделов: **Обои**, **Автосмена**, **Эффекты**, **Экраны**, **Настройки**. При первом открытии появляется интерактивный пошаговый гид с подсветкой нужного места; его можно повторить кнопкой **«? Показать гид»** или пропустить клавишей Esc.

## Новое в v3.0
- **Ровный рендер вне UI-потока:** отдельный QPC/high-resolution waitable-timer loop, DXGI Frame-Latency Waitable Swap Chain, лимиты 30/60/120/144/165 FPS. Перетаскивание окна Студии не останавливает обои; если драйвер не поддерживает waitable swap chain, включается совместимый fallback.
- **Быстрое переключение аудиоустройства:** WASAPI наблюдает за изменением основного выхода Windows и переподключает Loopback при замене Bluetooth/USB-наушников. Для треков используется Windows GSMTC (исполнитель — название) с запасным чтением заголовка аудиосессии.
- **Потоковые GIF:** WIC композитит только текущий кадр в общий canvas вместо распаковки сотен BGRA кадров в RAM.
- **Импорт без подвисания:** библиотека добавляет карточки сразу, а анализ видео/GIF и создание обложек выполняет отдельный worker.
- **Более лёгкая отрисовка виджетов:** кисти Direct2D переиспользуются; аудиоволна и кольцо сглаживаются кубическими кривыми.
- **Fit Blur для вертикальных роликов:** выберите `Blur-фон` в инспекторе — пустые боковые поля заполняются размытой и затемнённой копией видео.
- **Современный HTML5:** сначала пробуется установленный Edge WebView2/Chromium с загрузчиком без обязательного `WebView2Loader.dll`; при отсутствии доступен MSHTML fallback. Передаются движение мыши и WASAPI-спектр; HTML получает `wallpaperRegisterAudioListener(callback)` и `window.wallpulseInject(u, v, bass)`.
- **Упрощённые творческие инструменты:** быстрые пресеты (Оригинал, Кино, Неон, Тепло, VHS), один таймлайн с двумя маркерами обрезки, индивидуальная интенсивность 2.5D-параллакса и погоды.
- **Виджеты:** пять якорей или свободная позиция с настройкой X/Y и масштаба; русский календарь, Now Playing и ЦП/ОЗУ.
- **Настоящий Dual-Kawase:** несколько downsample/upsample GPU-проходов дают мягкий широкий Bloom и размытие для Fit Blur.
- **Погодные/частичные слои:** боке, неоновый дождь, снег и искры; аналитически рисуются на GPU поверх видео/GIF/шейдеров и реагируют на бас и курсор.
- **Пользовательские HLSL:** компиляция и горячая перезагрузка. При ошибке сохраняется последний рабочий шейдер (или безопасная сцена-запасной вариант), а Студия показывает диагностическую строку.
- **Масштабируемые панели:** колесо мыши прокручивает длинные вкладки, библиотеку и инспектор; отображается ненавязчивый скролл-индикатор.

Возможности v2.x сохранены: 8 стартовых сцен, независимые обои на дисплеях, плейлисты и расписание день/ночь, GPU-crossfade, WASAPI FFT/визуализатор, профили на сцену, ★ Избранное и фильтры, авто-акцент, прозрачная/акриловая панель задач, трим/бесшовный loop, глобальные хоткеи `Ctrl+Alt+P/N/M/W`.

## Первые шаги
1. Запустите `WallPulse.exe` и пройдите подсвечиваемый гид (или пропустите его).
2. В разделе **Обои** выберите готовую сцену либо нажмите **+ Добавить обои** / перетащите файлы в окно.
3. Нажмите **Применить**. В правой панели доступны масштаб и звук; в **PRO** — быстрые стили и тонкая коррекция.
4. В **Эффекты** включите визуализатор, виджеты, параллакс и погодный слой. В **Автосмена** настройте плейлист, избранное и расписание.
5. Для вертикального клипа используйте режим масштаба **Blur-фон**. Для HLSL откройте файл через библиотеку; после сохранения изменения применяются автоматически.

## Проверка и сборка
- **Windows x64 / Visual Studio 2022:**
  ```powershell
  cmake -S wallpulse -B wallpulse/build -A x64
  cmake --build wallpulse/build --config Release
  wallpulse/build/Release/WallPulse.exe --self-test
  ```
- **Zig C++ cross-build:**
  ```bash
  ./wallpulse/build_zig.sh ./release
  ```
- Конфигурация v2 автоматически переносится в новый формат v3 при первом запуске.
- Данные (настройки, обложки, WebView2 user data и стартовые сцены) хранятся в `%LOCALAPPDATA%\\WallPulse`; исполняемый файл остаётся автономным.
