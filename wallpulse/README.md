# WallPulse Studio v2.0.0 PRO — Живые обои, Шейдеры & Аудиовизуализация (Windows 10 / 11 x64)

Автономный однофайловый клон **Wallpaper Engine** на нативном C++17 (`Direct3D 11` + `Media Foundation DXVA2` + `WASAPI Loopback` + `Direct2D` + `WIC` + `OLE HTML5`).
Не требует установки сторонних библиотек — один портативный файл **`WallPulse.exe`**.

## Ключевые возможности v2.0.0 PRO
1. **Аудиовизуализатор WASAPI Loopback (`#1`)** — захват системного звука Windows (Spotify, YouTube, Яндекс Музыка, игры) без микрофона, 512-точечный FFT на 32 логарифмические полосы (`Столбцы`, `Неон-Волна`, `Неон-Кольцо`) + бас-реактивный пульс (`Bass Zoom & Glow`).
2. **Плейлисты, плавный GPU Crossfade и расписание «День / Ночь» (`#3`)** — автосмена по таймеру (`1/5/15/30/60 мин`), `Shuffle`, растворение сцен через GPU без чёрных вспышек и авто-переключение дневных/ночных обоев по часам.
3. **Независимые обои на каждый монитор (`#4`)** — отдельные `.mp4`, `.gif`, `shader://` или `.html` обои со своим профилем настроек одновременно на каждом дисплее (плюс режимы `Основной`, `Клон`, `Панорама Span`, `Один экран`).
4. **Виджеты на слое обоев позади значков (`#5`)** — полупрозрачные карточки: русские Часы и дата (`24ч / 12ч`, секунды), «Сейчас играет» (`IAudioSessionManager2`) и монитор загрузки `ЦП / ОЗУ`.
5. **PRO GPU-шейдеры постобработки (`#6`)** — `AMD CAS Sharpening` (адаптивная резкость), `Hue Shift` (`-180°..+180°`), `Bloom` (мягкое свечение), `Хроматическая аберрация` и ретро `VHS / ЭЛТ` фильтр.
6. **Обрезка видео `От — До` и бесшовный цикл (`#7`)** — выбор рабочего фрагмента ролика + плавный GPU Crossfade конца клипа с его началом без рывка.
7. **Прозрачная / Размытая панель задач Windows & Авто-акцент (`#8`)** — режимы `Полностью прозрачная` и `Акриловое стекло (Blur)` с чистым авто-восстановлением при выходе + автоподбор акцентного цвета интерфейса под активные обои.
8. **Индивидуальные профили, Избранное `★`, Поиск и Глобальные хоткеи (`#9`)** — сохранение настроек для каждого файла, фильтрация и кириллический поиск, хоткеи `Ctrl+Alt+P` (пауза), `Ctrl+Alt+N` (следующие), `Ctrl+Alt+M` (звук), `Ctrl+Alt+W` (Студия).
9. **Поддержка новых живых форматов (`#10`)** — видео (`.mp4`, `.webm`, `.mkv`, `.mov`, `.avi`), многокадровые анимации `.gif`, процедурные 60-FPS GPU-шейдеры (`shader://cyber_tunnel`, `shader://sunset_ocean`, `shader://matrix_pulse` и `.hlsl`) и интерактивные `.html` сцены!

## Сборка
- **Visual Studio 2022 / CMake (Windows x64):**
  ```powershell
  cmake -S wallpulse -B wallpulse/build -A x64
  cmake --build wallpulse/build --config Release
  ```
- **Кросс-компиляция через Zig C++:**
  ```bash
  ./wallpulse/build_zig.sh ./release
  ```
