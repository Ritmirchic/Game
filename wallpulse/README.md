# WallPulse Studio — Живые MP4 обои для Windows 10 / 11

**WallPulse Studio** — нативный однофайловый клон **Wallpaper Engine** для Windows 10 и Windows 11 (включая **Windows 11 24H2 / 25H2**), позволяющий в один клик поставить любое видео **`.mp4`** (а также `.webm`, `.mkv`, `.mov`, `.avi`, `.wmv`) на фон рабочего стола **позади иконок и панели задач**.

Программа скомпилирована в **единый автономный файл `WallPulse.exe`** на C++17 (Win32 + Direct3D 11 + HLSL Pixel Shader + Windows Media Foundation + Direct2D/DirectWrite) — не требует установки Python, .NET, Node.js, VLC или сторонних DLL.

---

## Возможности

- **Установка любого `.mp4` на рабочий стол за 1 секунду:**
  - Кнопка **«+ Выбрать MP4»** в верхней панели студии;
  - **Drag & Drop** — просто перетащите `.mp4` файл из Проводника прямо в окно программы;
  - Контекстное меню Проводника: **ПКМ по любому `.mp4` → «Поставить на рабочий стол (WallPulse)»**;
  - Запуск из командной строки: `WallPulse.exe "D:\Videos\wallpaper.mp4"`.
- **Полная совместимость с Windows 10 и Windows 11 (включая 24H2+):**
  - Автоматически определяет архитектуру рабочего стола Windows: классический слой `WorkerW` (Windows 10 / Windows 11 21H2–23H2) или новый композитный слой `Progman` (`WS_EX_NOREDIRECTIONBITMAP` + `WS_EX_LAYERED` под `SHELLDLL_DefView` в Windows 11 24H2+).
  - Автоматически переподключается при перезапуске `explorer.exe` или смене разрешения экрана (`PerMonitorV2` High-DPI).
- **Аппаратное декодирование и GPU-шейдеры (Direct3D 11 + Media Foundation):**
  - Аппаратное декодирование H.264 / MP4 видеокартой и бесшовное зацикливание (`Loop`).
  - Режимы масштабирования: **Заполнение (Cover)**, **Вписать + размытый фон** (идеально для вертикальных 9:16 видео!), **Вписать (чёрные поля)**, **Растянуть**.
  - Реалтайм GPU-эффекты как в Wallpaper Engine: **Яркость**, **Контрастность**, **Насыщенность**, **Затемнение под иконки**, **Скорость видео (0.25× – 2.00×)** и **3D-параллакс за курсором мыши**.
- **Умная экономия ресурсов (0% CPU / GPU в играх):**
  - Автоматически ставит декодирование и рендеринг на паузу, когда вы разворачиваете браузер/редактор на весь экран или запускаете полноэкранную игру, и мгновенно возобновляет анимацию при возврате на рабочий стол.
  - Умное отключение звука при переключении в другие окна + экономия заряда от батареи ноутбука.
- **Поддержка нескольких мониторов:**
  - Одинаковые обои на всех мониторах (единый декодер — без лишней нагрузки), единая панорама через все экраны или вывод на выбранный монитор.
- **Системный трей и автозапуск с Windows:**
  - Сворачивается в системный трей возле часов, запоминает библиотеку и активные обои после перезагрузки ПК.
- **3 встроенных живых `.mp4` обоев из коробки:**
  - При первом запуске автоматически создаёт 3 демонстрационных цикличных `.mp4` ролика (*Неоновый Синтвейв*, *Северное Сияние*, *Космическая Туманность*), чтобы живые обои заработали сразу при открытии.

## Сборка из исходников

### Вариант 1: Windows (Visual Studio 2022 / CMake)
```powershell
cd wallpulse
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
# Готовый бинарник: wallpulse\build\Release\WallPulse.exe
```

### Вариант 2: Кросс-компиляция на Linux / macOS через Zig C++
```bash
./wallpulse/build_zig.sh ./release
# Готовый бинарник: ./release/WallPulse.exe
```

### Автоматическая самопроверка на Windows
```powershell
.\WallPulse.exe --self-test TEST_REPORT.txt STUDIO_SCREENSHOT.bmp
```
