# WallPulse Pocket — мобильные версии

Мобильная companion-версия WallPulse Studio с библиотекой обоев, импортом файлов с телефона, избранным и полноэкранным предпросмотром.

## Возможности

- демо-сцены, фильтры и избранное;
- импорт фото, GIF и видео через системный файловый выбор;
- циклический предпросмотр видео, кадрирование, звук и экономия трафика;
- локальное хранение добавленных файлов в IndexedDB;
- экспорт/передача файлов, PWA-установка и офлайн-интерфейс;
- нативная Android-оболочка APK в [`../android/`](../android/): сохраняет файлы в `Downloads/WallPulse` и передаёт статические изображения системному выбору обоев.

## Android APK

Сборка и проверка APK выполняются GitHub Actions. После успешной сборки установочный APK публикуется здесь:

`https://github.com/Ritmirchic/Game/releases/download/wallpulse-pocket-android-v1.0.0/WallPulse-Pocket-Android.apk`

APK предназначен для sideload-установки и подписан Android debug-сертификатом; публикация в Google Play не выполнялась. На Android для видеообоев может понадобиться отдельное совместимое приложение живых обоев.

## PWA / iPhone

PWA требует HTTPS-хостинг (или localhost для разработки), так как Service Worker не запускается из `file://`.

Для быстрой проверки из корня репозитория:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Затем откройте `http://localhost:4173/wallpulse/mobile/`. Для установки на iPhone разместите папку `wallpulse/mobile` на HTTPS-хостинге, откройте адрес в Safari и выберите **Поделиться → На экран «Домой»**. Браузерная версия сохраняет фото для ручного назначения через приложение «Фото»; системные живые обои напрямую назначать из PWA нельзя.

WallPulse Studio для Windows остаётся отдельным приложением; мобильная версия не меняет его настройки.
