# WallPulse Pocket — мобильные версии

Мобильный companion-app WallPulse Studio с библиотекой обоев, импортом медиа с телефона и предпросмотром.

## Android APK — живые обои

Android-приложение включает нативный `WallpaperService` и действительно устанавливает личные MP4/GIF как живые обои:

1. Нажмите **＋** и выберите MP4 или GIF.
2. Откройте карточку и нажмите **«Установить живые обои»**.
3. В системном предпросмотре Android нажмите **«Установить»**, выберите главный экран, экран блокировки или оба (варианты зависят от устройства).

Видео воспроизводится циклически и без звука; GIF анимируется. Сервис ставится на паузу, когда обои скрыты. Рекомендуется MP4 (H.264) или обычный GIF; фактическая поддержка кодеков зависит от телефона. Фото можно назначить статическими системным способом.

## PWA / iPhone

PWA устанавливается из HTTPS-хостинга и поддерживает импорт, предпросмотр, избранное и сохранение файлов. На iPhone она не может назначать системные живые обои напрямую.

Для локальной проверки из корня репозитория:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Откройте `http://localhost:4173/wallpulse/mobile/`. Для установки PWA на iPhone разместите папку `mobile/` на HTTPS-сайте, откройте страницу в Safari и выберите **Поделиться → На экран «Домой»**.
