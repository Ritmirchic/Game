# 🌀 TESSERACT RIFT — это не 3D. Это 4D.

> Обычные игры живут в трёх измерениях. Эта — в **четырёх**.

**[⬇ СКАЧАТЬ ИГРУ (.zip) — прямая ссылка](https://github.com/Ritmirchic/Game/archive/refs/tags/v2.0.0.zip)** · **[📦 Релиз v2.0.0](https://github.com/Ritmirchic/Game/releases/tag/v2.0.0)**

## 🤯 В чём гениальность?

Каждый объект в игре живёт в настоящем четырёхмерном пространстве **ℝ⁴ (x, y, z, w)**.
Рендер честно считает цепочку проекций, которой нет ни в одном обычном 3D-движке:

```
ℝ⁴ ──(повороты в 6 плоскостях, включая XW, YW, ZW)──▶
стереографическая проекция 4D→3D ──▶ перспектива 3D→2D
```

Никакого Three.js, никакого WebGL-движка — **один HTML-файл, чистый Canvas и математика**.
Открой `index.html` в любом браузере — игра работает даже офлайн.

## 🎮 Как играть

Ты — пилот гипер-корабля внутри тессеракта (4D-куба). Собери **12 гипер-ядер** быстрее Охотников измерений.

| Клавиши | Действие |
|---|---|
| `W A S D` | лететь |
| **`Q` / `E`** | **путешествие по 4-й оси W** ★ |
| Мышь (клик по экрану) | обзор |
| `Space` / `C` | вверх / вниз |
| `Shift` | форсаж |
| Колесо мыши | вращать само гиперпространство ★ |
| `P` | пауза |

★ — механики, физически невозможные в 3D-играх.

## 💡 Ключевая механика

- Ядро **материально** только когда твой W-срез совпал с его W (шкала внизу экрана + звуковой маяк: чем ближе — тем выше писк).
- Далеко по W ты — **призрак**: враги и мины не могут тебя тронуть. Но и ядро призраку не взять.
- Проходи *сквозь* 3D-стены, смещаясь в четвёртое измерение. В этой игре стена — лишь срез.

## 🚀 Запуск

Скачай, распакуй, открой `index.html`. Всё. Сервер не нужен.

## 🏗 Стек

- 1 файл: HTML + CSS + JS (~32 КБ)
- Собственный 4D-движок: тессеракт (16 вершин / 32 ребра), 16-cell и 5-cell как игровые сущности
- Весь звук синтезируется через WebAudio — ни одного аудиофайла
