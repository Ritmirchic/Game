# ПОСЛЕДНИЙ МАЯК

Атмосферная low-poly выживалка для коротких сессий: днём вы собираете ресурсы и укрепляете остров, ночью защищаете последний маяк от Пепельных.

Этот репозиторий содержит **полностью играбельный браузерный 3D-вертикальный срез идеи для Roblox**, собранный на TypeScript и Three.js. Здесь уже есть законченный игровой цикл от старта до победы или поражения. Для запуска не нужны Roblox Studio, внешние модели, текстуры или аудиофайлы.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Production-сборка:

```bash
npm run build
npm run preview
```

Автономный HTML со встроенными скриптами, стилями и шрифтами:

```bash
npm run build:html
```

Команда создаёт `last-beacon.html` в корне проекта. Этот файл можно скачать и открыть напрямую в браузере без сервера и интернета.

## Как выиграть

1. Добывайте **древесину, металл и энергетические осколки**.
2. Подойдите к маяку и установите три энергоячейки. Каждая стоит **6 металла + 4 осколка**.
3. Третья ячейка запускает финальный пепельный штурм.
4. Продержитесь **40 секунд**, не дав маяку разрушиться.

Вы проиграете, если погибнет выживший или прочность маяка упадёт до нуля.

## Что реализовано

- процедурный трёхмерный остров с морем, руинами, растительностью и блоковым персонажем;
- добыча с запасом каждого ресурсного узла и восстановлением на рассвете;
- смена дня и ночи, туман, звёзды, падающий пепел и динамическое освещение;
- три вида Пепельных: обычный, быстрый и тяжёлый;
- враги выбирают между игроком, постройками и маяком;
- баррикады и автоматические турели с разрушением;
- ремонт маяка, аптечки, здоровье, выносливость, бег и прыжки;
- три энергоячейки, финальный штурм, победа и два варианта поражения;
- процедурные звуки и фоновый шум ветра через Web Audio;
- главное меню, обучение, пауза, уведомления, статистика и локальный рекорд;
- управление с клавиатуры/мыши и сенсорный режим с джойстиком;
- адаптивный интерфейс на русском языке.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | `WASD` / стрелки / левый сенсорный джойстик |
| Бег | `Shift` |
| Прыжок | `Space` / сенсорная кнопка |
| Добыча и установка ячейки | `E` / сенсорная кнопка |
| Атака | `F` или левая кнопка мыши / сенсорная кнопка |
| Обзор | Зажмите кнопку мыши и ведите / свайп по миру |
| Масштаб камеры | Колесо мыши |
| Баррикада | `1` — 5 древесины, 2 металла |
| Турель | `2` — 7 металла, 2 осколка |
| Ремонт маяка | `3` — 3 древесины, 3 металла, только рядом с маяком |
| Аптечка | `4` — 2 металла, 1 осколок |
| Пауза | `P` |

На кнопки крафта можно нажимать мышью или пальцем. Если ресурсов не хватает, игра сообщит точное количество.

## Структура

```text
src/
  main.ts                 интерфейс, экраны и сенсорное управление
  style.css               адаптивный визуальный стиль
  game/
    Game.ts               игровой цикл, бой, добыча, крафт и AI
    Environment.ts        остров, океан, освещение и погода
    models.ts             процедурные модели персонажей и объектов
    Soundscape.ts         синтезированные звуки
    types.ts              общие типы
GAME_DESIGN.md            концепт и план развития Roblox-версии
```

Проверка проекта: `npm run build` выполняет строгую проверку TypeScript и собирает production-бандл.
