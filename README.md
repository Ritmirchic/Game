# ПОСЛЕДНИЙ МАЯК

Атмосферная браузерная 3D-выживалка: днём вы собираете ресурсы и укрепляете остров, ночью защищаете последний маяк от Пепельных.

Текущая версия перенесена на **Babylon.js 9 + TypeScript**. Это полностью играбельный цикл от старта до победы или поражения, а не Roblox `.rbxl` и не статичный концепт.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

### Один автономный HTML

```bash
npm run build:html
```

Команда создаёт `last-beacon.html` в корне проекта. В файл встраиваются JavaScript, CSS, шрифты, favicon, GLB-модели, environment-карта и все текстуры. Его можно открыть напрямую через `file://` **без сервера и интернета**.

## Как выиграть

1. Добывайте **древесину, металл и энергетические осколки**.
2. Подойдите к маяку и установите три энергоячейки. Каждая стоит **6 металла + 4 осколка**.
3. Третья ячейка запускает финальный пепельный штурм.
4. Продержитесь **40 секунд**, не дав маяку разрушиться.

Вы проиграете, если погибнет выживший или прочность маяка упадёт до нуля. Ночью следите не только за здоровьем, но и за теплом.

## Графика

- Babylon.js, WebGL2 и физически корректные PBR-материалы;
- фотографические текстуры травы, песка, коры и древесины, normal/roughness-карты;
- environment lighting с локальной `.env`-картой;
- рельефный остров и отдельная геометрия береговой линии;
- вода с волнами, normal-map, отражением и преломлением;
- PCF soft shadows, SSAO2 на десктопном профиле, ACES, bloom и FXAA;
- альфа-тестируемая объёмная листва, ветви и кора вместо гранёных крон;
- скелетные анимации выжившего и противников;
- детализированный маяк с металлом, медными трубами, крепёжными элементами, оптикой и световым лучом.

Мобильный профиль уменьшает разрешение теней и отражений и отключает SSAO. Для слабого десктопа также доступен запуск с `?quality=low` в dev-версии.

## Игровые системы

- добыча с запасом каждого узла и восстановлением на рассвете;
- день/ночь, туман, звёзды, пепел и динамическое освещение;
- три типа Пепельных с разными характеристиками;
- выбор цели, разделение в толпе, обход горящих костров и телеграфируемые замахи;
- здоровье, выносливость, бег и **тепло**;
- **уклонение** с затратой выносливости и короткой неуязвимостью;
- разрушаемые баррикады и автоматические турели;
- **костры с выгоранием**, дозаправкой дровами, восстановлением тепла и уроном врагам;
- трофейный металл с врагов, ремонт и аптечки;
- три ячейки, финальный 40-секундный штурм, победа и поражение;
- процедурный звук через Web Audio, обучение, пауза, статистика и локальный рекорд;
- полевой HUD с числовыми показателями, состояниями ранения/холода и адаптивным крафтом;
- клавиатура/мышь и сенсорное управление.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | `WASD` / стрелки / левый сенсорный джойстик |
| Бег | `Shift` |
| Уклонение | `Space` или `Q` / сенсорная кнопка «Рывок» |
| Добыча, ячейка, дозаправка | `E` / сенсорная кнопка |
| Атака | `F` или одиночный клик ЛКМ / сенсорная кнопка |
| Обзор | Перетаскивание ЛКМ или ПКМ / свайп по миру |
| Масштаб камеры | Колесо мыши |
| Баррикада | `1` — 5 древесины, 2 металла |
| Турель | `2` — 7 металла, 2 осколка |
| Костёр | `3` — 4 древесины, 1 металл |
| Ремонт маяка | `4` — 3 древесины, 3 металла, только рядом с маяком |
| Аптечка | `5` — 2 металла, 1 осколок |
| Пауза | `P` или `Escape` |

Дозаправка костра стоит **2 древесины** и добавляет 55 секунд горения. На кнопки крафта можно нажимать мышью или пальцем.

## Структура

```text
src/
  main.ts                 интерфейс, экраны и сенсорное управление
  style.css               меню, экраны и базовый визуальный стиль
  hud.css                 полевой игровой HUD и его адаптивные режимы
  game/
    Game.ts               игровой цикл, бой, тепло, добыча, крафт и AI
    Environment.ts        PBR-остров, океан, освещение и постпроцессинг
    models.ts             материалы, GLB-загрузка, модели и эффекты
    assets.ts             локальные URL / встроенные offline data URI
    Soundscape.ts         синтезированные звуки
    types.ts              общие типы
public/assets/            локальные модели и текстуры
scripts/build-html.mjs    сборка полностью автономного HTML
ASSETS.md                 источники, авторы и лицензии
GAME_DESIGN.md            исходный концепт и направления развития
```

Проверка проекта: `npm run build` выполняет строгую проверку TypeScript и собирает production-бандл.
