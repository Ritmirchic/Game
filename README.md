# 🌌 ГИПЕРСДВИГ / HYPERSHIFT

**3D-платформер, где четвёртое измерение — это механика.**

Вы видите не «обычное 3D», а **трёхмерный срез четырёхмерного мира**. Призрачные
каркасные контуры вокруг вас — это соседние слои реальности по оси W. Нажимая
**Q/E**, вы сдвигаетесь поперёк бытия: платформы растворяются, другие проявляются
из пустоты, а весь мир меняет цвет.

## Задача
Собрать **12 осколков тессеракта**, разбросанных по 5 слоям W (от −2 до +2),
избегая **Теней** — существ, которые чувствуют вашу координату W и фазируют
вслед за вами. Собрав всё, откройте **Врата Тессеракта** на вершине спирали.

## Управление
| Клавиша | Действие |
|---|---|
| **W A S D** | движение |
| **Мышь** | обзор (клик — захват курсора) |
| **Пробел** | прыжок |
| **Shift** | спринт |
| **Q / E / колесо** | **гиперсдвиг** — движение по 4-й оси W |
| **M / R / Esc** | звук / респавн / пауза |

Главный приём: **прыжок через пропасть + гиперсдвиг в полёте** — приземляешься
на платформу, которой мгновение назад не существовало.

## Запуск
Игра — статичные файлы, движок и ассеты не нужны:
- онлайн: откройте `hypershift/index.html` через любой статичный сервер, либо
- офлайн: скачайте ZIP из [Releases](../../releases), распакуйте, откройте `index.html` — работает без интернета.

## Технологии
- **three.js r128** (WebSocket-free, один `three.min.js`, лежит рядом)
- физика, коллизии, ИИ врагов, звук и музыка — **полностью синтезированы кодом** (WebAudio, без единого аудиофайла)
- все текстуры (свечения) генерируются на canvas при запуске
- ~800 строк собственной логики: 4D-фазировка объектов, AABB-физика с чекпоинтами, генеративный эмбиент
