# ГИПЕРКУБ · игра в 4D

Одна HTML-страница, ноль зависимостей, ноль библиотек. Вся математика — 4D → 3D → 2D — написана руками.

## Что происходит

Ты летаешь внутри **тессеракта** (4-мерного куба), который вращается не только в
привычных плоскостях XY, XZ, YZ, но и в плоскостях **с участием четвёртой оси**:
XW, YW, ZW. Из-за этого кристалл выворачивается наизнанку и «дышит» прямо у тебя
на глазах, а осколки света уезжают в направлении, которое невозможно показать
жестом — его нет в трёхмерном мире.

- Собери **6 осколков** (они дрейфуют вместе с 4D-вращением мира).
- Открывается **ядро** — оно всегда в центре гиперкуба. Лети в него.
- Розовые рёбра — это рёбра, вытянутые **вдоль оси W**. Именно они выдают
  присутствие четвёртого измерения.
- Компас по краям экрана показывает, куда уехал ближайший осколок.
- Каждое столкновение с осколком на миг **ускоряет вращение в 4D** — мир
  вздрагивает и перестраивается.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W A S D` / стрелки | полёт |
| мышь | обзор |
| `SPACE` / `Q` | вверх |
| `SHIFT` / `F` | вниз |
| `ESC` | пауза |
| `M` | звук вкл/выкл |

Тач: левая половина экрана — джойстик движения, правая — обзор.

## Запуск

Открой `index.html` в браузере. Всё, больше ничего не нужно.

```bash
python3 -m http.server 8000   # если хочется через локальный сервер
```

## Внутри

- 16 вершин, 32 ребра тессеракта, матрицы 4×4, шесть плоскостей вращения.
- Проекция 4D→3D — перспектива по оси W (`k = 1.9 / (3.2 − w)`), потом обычная
  перспектива в 2D. Отсюда и «невозможный» вид: дальние по W рёбра становятся
  большими и яркими.
- 340 частиц пыли тоже живут в 4D и пролетают мимо камеры.
- Рендер — Canvas 2D: аддитивное свечение, шлейфы осколков, лёгкий motion blur
  вместо полной очистки кадра.
- Звук — процедурный WebAudio (дрон, который реагирует на скорость, и блипы при
  подборе).
