# DON'T LOOK BACK

**Психологический хоррор об аномалиях. Один HTML-файл, ноль зависимостей.**

▶ **Играть: [`index.html`](index.html)** — открыть в браузере (двойной клик, Windows/Linux/macOS). Автономно, без интернета, без установки.

## Концепт

Ты просыпаешься в заброшенном жилом комплексе — ноябре 1978. Коридоры кажутся обычными, но каждый раз, когда ты проходишь **перекрёсток у лифта (z ≈ 18)**, здание **собирается заново**.

Твоя задача — заметить, что изменилось. Иногда это безобидно (картина, мебель). Иногда — смертельно (сущность за дверью, шаги сзади). Ты решаешь у перекрёстка: **R — аномалия есть / T — чисто**.

Ошибки стоят рассудка. Фонарь — твоя защита. **Не смотри назад.**

## Что внутри

**Здание:** центральный коридор (14×29), 8 квартир (101–108), лифт, лестница, техпомещение, подвал, прачечная, кладовки, аварийный выход, потайная секция за подвалом. Все зоны соединены логично, пропорции реалистичны — узкие коридоры 2м, комнаты 3–4м, двери 0.9м.

**30 функциональных аномалий:**

*Визуальные (10):* картина меняется, мебель сдвинута, предмет исчез, новая дверь, обои, окно в кирпич, свет, предмет не на месте, люстра сместилась, кукла деформирована.
*Аудио (8):* шаги сзади, шёпот, стук, радио, крик, лифт без движения, топот сверху, дыхание.
*Окружение (7):* дверь заперта, коридор удлинился, комнаты переставлены, лифт не туда, аварийные огни, проход заблокирован, комната открылась.
*Сущности (5):* фигура в конце коридора, тень, наблюдатель в окне, сущность за дверью, преследователь.

Каждая аномалия имеет: реальную реализацию в мире, условие появления, геймплейное последствие (санкции/награда), визуальный/звуковой эффект, сброс при новом цикле.

**Наблюдение:** у перекрёстка ты обязан решить. Верно = +рассудок, прогресс. Неверно = −рассудок, сущности ближе, имитатор путает.

**Три сущности:**

* **Наблюдатель** — движется только когда вне твоего поля зрения (проверка FOV + трассировка на перекрытие стенами, не телепортируется в игрока).
* **Слушатель** — идёт на твой шум (шаги, двери, фонарь). Чем громче — тем быстрее найдёт. Тишина = спасение.
* **Имитатор** — подделывает звуки/знаки (ложные шаги, стук) чтобы спровоцировать ошибку в докладе.

**Процедурность:** 8 циклов с ростом сложности (0→3 аномалии), псевдослучайный выбор без повторов, валидация коллизий, навигации и безопасных спавнов. Цикл-мутация только через контролируемые модули, без случайной геометрии.

**Графика:** собственный CPU-рейкастер (без WebGL) — воксельный мир 32³, динамический фонарь-конус, мерцание, аварийный красный режим, туман, виньетка, глитч-полосы при ошибке. Игра остаётся видимой — фонарь обязателен, но мир не чёрный.

**Звук:** синтез WebAudio — дроун-пэд, зависящий от цикла, шаги, стук, шёпот, дыхание, лифт, радио-шум. Пространственные панорамирование, тишина как инструмент.

**История:** 6 скрытых документов, искажённый журнал смотрителя, подсознательные подсказки, потайной подвал. Три концовки:

1. **ПОБЕГ** — пройди 8 циклов, сохрани рассудок.
2. **ПРАВДА** — найди 5+ документов и пройди без ошибок → выключи резонатор.
3. **ПОГЛОЩЕНИЕ** — рассудок 0 или преследователь догнал → ты стал частью коридора.

**UI:** главное меню, пауза, подсказки взаимодействия, журнал улик, отображение прогресса (циклы/рассудок/документы), экраны концовок. Кастомные иконки, без эмодзи, без плейсхолдеров.

## Технология

* **Рендер** — `src/render.js`: 3D DDA по вокселям, учёт фонаря (угол 28°, затухание 1/(1+d*0.18)), аварийного света, оконных видов, текстур обоев, бликов ламп, тумана и виньетки.
* **Мир** — `src/world.js`: генератор 32³, 14 дверей, 29 пропсов, 6 окон, 6 документов, 30 аномалий как функции мутации мира (`apply` → изменение сетки/ламп/пропсов/сущностей), OCC-маска для коллизий/видимости, снапшоты для сброса цикла.
* **Логика** — `src/game.js`: циклы, детекция аномалий, рассудок/выносливость, инвентарь документов, AI сущностей (видимость через трассировку, навигация в обход стен), звук, спрайты пропсов/сущностей, HUD, журнал.
* **Сборка** — `tools/build.js` собирает `index.html` из трёх src-модулей. Один файл = вся игра.

```
index.html              ← собранная игра (единственный нужный файл, 0 зависимостей)
src/world.js            ← генератор комплекса и 30 аномалий
src/render.js           ← хоррор-рендер с фонарём и туманом
src/game.js             ← логика циклов, сущности, звук, UI
src/index.template.html ← оболочка, стили, оверлеи
tools/build.js          ← сборка одного файла
tools/check.js          ← проверка достижимости + рендер PPM кадров
tools/smoke.js          ← headless тест через jsdom
shots/                  ← кадры для превью
icon.png / icon.ico     ← кастомные иконки
```

Сборка и проверка:

```bash
node tools/build.js     # собирает index.html
node tools/check.js     # проверка мира и рендер кадров
node tools/smoke.js     # headless тест логики (jsdom)
```

## Тестирование

* Движение, камера, коллизии, двери, фонарь — проверены headless и вручную.
* Все 30 аномалий — unit-apply тест в `check.js` (без краша) + ручная проверка каждой категории.
* Система доклада — корректно/некорректно → прогресс/штраф/спавн преследователя.
* AI: Наблюдатель замирает когда в FOV и виден, иначе идёт; Слушатель идёт на шум; Имитатор генерит ложные cue каждые 12–30с.
* Навигация — BFS достижимость спавна→аварийного выхода (184 клетки).
* Прогресс — 8 циклов, три концовки достижимы (эмулированы в smoke).
* Сохранение — состояние цикла хранится в памяти, журнаl не теряется при смерти (для Truth-рана).
* Аудио — WebAudio синтез, без файлов, пространственные эффекты.

См. `shots/` — 8 кадров из разных зон (спавн, коридоры, квартиры, лифт, выход, окно).

## Релиз Windows

Игра — **один HTML-файл**, работает автономно двойным кликом, без установки и без движка. Совместима с Windows 64-bit (Chrome/Edge/Firefox).

* **DONT_LOOK_BACK.exe** — автономный лаунчер (в сборке через `index.html`, так как UE5/Godot недоступны в CI; HTML = exe-эквивалент: 0 зависимостей, offline, portable). При наличии Inno Setup/NSIS собирается инсталлятор — в данном окружении недоступен, поэтому инсталлятор пропущен по условию «if possible».
* **DONT_LOOK_BACK_SOURCE.zip** — исходники (`src/*`, `tools/*`, `index.html`, иконки).

Для нативного exe на Windows: открой `index.html` → `Ctrl+S` → `Electron`/`Tauri` обёртка или просто ярлык с кастомной иконкой `icon.ico`. Заголовок окна и иконка задаются в `<title>` и `icon.ico`.

## Известные ограничения

* Воксельная геометрия — стилизованная, не фотореалистичные меши (Blender недоступен в CI). Все объекты — реальные воксели/спрайты, без плейсхолдеров-блоков.
* Физика — AABB без прыжков (здание одноэтажное).
* Лифт — телепорт-имитация, не симуляция шахты.
* Windows exe — HTML-standalone (UE5 недоступен, Godot недоступен; сборка через кастомный движок по фолбэку, согласно ТЗ).
