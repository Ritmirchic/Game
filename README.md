# ГИПЕРСРЕЗ / HYPERCUT

**3D-лабиринт, у которого есть четвёртая ось.**

Это не «ещё один 3D-шутер в браузере». Здесь мир четырёхмерный: у каждой стены кроме
длины, высоты и толщины есть ещё координата **W**. Вы живёте на трёхмерном срезе этого
мира — и видите только те стены, которые пересекают ваш срез.

Отсюда всё остальное:

- часть стен существует только при `W < 0` (янтарные), часть — только при `W > 0` (фиолетовые),
  а некоторые — в узкой полосе значений W;
- **Q / E** сдвигают вас по четвёртой оси. Стена, которая была перед вами, может перестать
  существовать — не потому что она «сломалась», а потому что вы вышли из той плоскости,
  в которой она стояла;
- **TAB** включает 4D-зрение: весь уровень проецируется из 4D в 3D, и вы видите то,
  чего в вашем срезе нет.

Цель: собрать 6 осколков и дойти до ядра-тессаракта.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` | идти |
| мышь / стрелки | смотреть |
| `Space` | прыжок |
| `Shift` | бег |
| `Q` / `E` | сдвиг по 4-й оси (W) |
| `Tab` | 4D-зрение |
| `Esc` | пауза |

## Что внутри (без библиотек)

- собственный рендерер на Canvas 2D: 4D → 3D-срез → перспективная проекция;
- клиппинг полигонов по ближней плоскости, сортировка граней по глубине, туман;
- 4D-проекция гиперструктуры уровня для режима «4D-зрение» и титульного экрана;
- настоящий тессаракт (16 вершин, 32 ребра) с вращением в плоскостях XW/YW/ZW;
- трассировка луча для окклюзии объектов (осколки за стеной — только призрак);
- процедурный лабиринт (DFS + петли), физика AABB, звук на WebAudio;
- одна HTML-страница, ноль зависимостей, работает офлайн.

## Запуск

Откройте `hypercut.html` в браузере. Всё.

## Разработка

```bash
node dev/headless-test.js   # прогон логики без браузера (мок canvas + DOM)
```

Тест проверяет: отсутствие исключений, работу 4-й оси (стена есть при одном W и исчезает при другом),
сбор осколков, финиш, устойчивость к 600 кадрам случайного ввода и что рендер реально рисует.

`hypercut.html` — единственный файл поставки.
