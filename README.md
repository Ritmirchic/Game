# ЭХО / 05:00

Небольшая самостоятельная браузерная игра о времени, памяти и собственных следах.

Каждые 24 секунды игровая комната возвращает игрока к началу витка, но оставляет предыдущее движение в виде живого эха. Эхо повторяют маршрут и импульсы, поэтому несколько версий игрока постепенно учатся действовать вместе.

## Запуск

Откройте [`index.html`](./index.html) в современном браузере — сборка, сервер и внешние ассеты не нужны.

- **WASD / стрелки** — движение
- **Space / клик** — импульс
- **M** — звук
- **Esc** — пауза

На телефоне ведите пальцем; короткий тап создаёт импульс.
