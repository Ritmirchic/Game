# ПЕТЛЯ

Неоновая аркада, в которой ты сражаешься **с собственным прошлым**.

## Идея

Ты — светящийся сгусток энергии. Каждые **18 секунд** время зацикливается:
в арене появляется призрак, который в точности повторяет твой маршрут прошлой петли.
Коснулся себя прошлого — погиб. С каждой новой петлёй призраков становится больше,
и все они одновременно проживают свои записи. Лабиринт строишь ты сам.

## Как играть

- **WASD** или **стрелки** — движение
- на телефоне — веди палец по экрану (виртуальный джойстик)
- **M** — звук вкл/выкл, **P** — пауза, **Enter/R** — рестарт
- собирай золотые сферы (комбо ×5 за быстрые подборы), не приближайся к призракам —
  красная виньетка предупредит об опасности

## Особенности

- механика эхо-записи: детерминированный фиксированный шаг 1/60 с, запись и воспроизведение траекторий
- процедурный звук на WebAudio (эмбиент-пад, синтез SFX, без единого внешнего файла)
- частицы, тряска экрана, неоновое свечение, шлейфы, эффект зацикливания времени
- рекорд в localStorage, поддержка мобильных экранов и пауза при сворачивании вкладки

## Запуск

Игра — один самодостаточный файл, без зависимостей и сборки.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Либо просто открой `index.html` в браузере.
