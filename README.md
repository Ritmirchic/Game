# СИНГУЛЯРНОСТЬ 🌌

**Ты — чёрная дыра.** Аркада о гравитации, голоде и соперничестве двух сингулярностей.
Чистый JavaScript + Canvas + WebAudio. Ноль картинок, ноль аудиофайлов, ноль зависимостей —
вся графика и весь звук синтезируются в браузере в реальном времени.

## Запуск

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000
```

(Можно и просто открыть `index.html` — но через сервер надёжнее для шрифтов и localStorage.)

## В чём гениальность

- **Гравитационное линзирование по-настоящему.** Фоновые звёзды отклоняются по закону
  `θ ∝ M/r²`, растягиваются в кольцо Эйнштейна и исчезают за тенью фотонной сферы —
  как на снимках телескопа Event Horizon.
- **Аккреционный диск рождается сам.** Пыль спавнится на околокруговых орбитах,
  сопротивление среды гасит орбиты — и материя спирально падает за горизонт.
  Никаких заскриптованных анимаций, только физика.
- **Соперница-сингулярность.** Каждая волна приходит другая чёрная дыра. Вы едите
  одну и ту же пыль, растёте и притягиваетесь. Слияние неизбежно — и побеждает
  в нём просто более массивная. Вся игра — гонка за массу.
- **Сила в размене со скоростью.** Чем ты массивнее, тем медленнее и неповоротливее.
  Большой = сильный, но лёгкая добыча успевает удрать. Маленький = быстрый, но хрупкий.
- **Гравитационный импульс [ПРОБЕЛ].** Отталкивает всё вокруг — но сжигает 12% твоей
  массы. Последний шанс спастись от слияния, которое ты проиграешь.
- **Звук слияния — «чирп» GW150914.** Тот самый сигнал гравитационных волн,
  который поймал LIGO: экспоненциальный свип 48→900 Гц, ringdown и эхо
  в процедурном ревербераторе. Весь саундтрек (дрон, пэды, сердцебиение при
  опасности) генерируется WebAudio-синтезом и зависит от твоей массы.
- **Фрегаты человечества** паникуют, удирают и стреляют лазерами — а фотоны летят
  с постоянной скоростью, но их траектории изгибаются гравитацией. Свет не уходит.
- **Кинематографичные слияния:** slow-mo, ударные волны, тряска камеры, вспышки.
  Смерть — тоже зрелище: камера наблюдает, как победительница живёт без тебя.

## Управление

| | |
|---|---|
| Мышь / тач | сингулярность тянется к курсору |
| WASD / строчки / ЦФЫВ | то же самое с клавиатуры |
| **ПРОБЕЛ** / ПКМ | гравитационный импульс (−12% массы) |
| P / Esc | пауза |
| M | звук вкл/выкл |

## Правила

1. Поглощай пыль, искры и фрегаты — масса растёт.
2. Волнами приходят соперницы. Следи за полосами массы в HUD:
   **при слиянии побеждает та, что тяжелее.**
3. Тяжелее — значит медленнее. Импульс помогает сбежать, но обедает.
4. Если тянуть время, соперница впадает в ярость и идёт на таран.
5. Счёт = поглощённая материя × множитель волны + слияния. Рекорд хранится локально.

## Структура

```
test/smoke_lib.js стабы DOM/Canvas/rAF для headless-прогона
```

## Тесты

```bash
node test/smoke.js
```

Прогоняет меню → старт → питание → волну → импульс → слияние → смерть/победу → рестарт
без браузера, проверяя физику на NaN и логику на здравый смысл.
