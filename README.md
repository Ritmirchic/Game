# НЕЕВКЛИД

Процедурный неевклидов лабиринт от первого лица. **Ноль внешних ассетов**: каждая текстура,
каждый спрайт и каждый звук синтезируются кодом в момент запуска. Движок — собственный
raycaster на чистом JavaScript, без библиотек.

```
npm test          # три комплекта проверок: генерация, игровой цикл, рендер
npm start         # статический сервер на :8080 → открыть http://localhost:8080
```

Нужен только браузер. Для headless-тестов рендера — `npm i` (ставит `@napi-rs/canvas`,
используется исключительно тестами; без него `tests/render.test.js` честно пропускается).

## Что здесь невозможного

| Явление | Как работает |
|---|---|
| **Разломы** | Пары тайлов, сшитых в другом месте карты и повёрнутых на 90/180/270°. Шагнул — оказался не там и не так повёрнутым. Обратный проход возвращает ориентацию. |
| **Квантовые двери ◊** | Тайл твёрдый и видимый, *только пока находится в конусе взгляда* (с учётом прямой видимости). Отвернулся — дверь исчезает и становится проходимой: проходишь спиной. |
| **Наблюдатели** | Двигаются по A\*, только когда на них **не** смотрят. Под взглядом замирают; если смотреть слишком долго — исчезают. Догнали — забирают осколок или переносят тебя. Не понимают квантовых дверей: за дверью, на которую смотришь, они не пройдут. |
| **Врущая карта** | Миникарта рисует исследованное, но повёрнутым на случайный угол; после каждого разлома угол меняется заново. Перестаёт врать только когда собраны все 5 осколков — и тогда же открывает дверь выхода и показывает разломы. |
| **Компас** | Честный: всегда указывает на ближайший осколок (и на выход после 5/5). Частота звона осколка растёт с близостью. |
| **Зоны** | Четыре региона с разными палитрами стен/пола/тумана и своим звуковым дроном: ПРЕДДВЕРИЕ, АРХИВ, ГАЛЕРЕЯ, НИЖНИЙ ЯРУС. |

Цель: собрать 5 осколков реальности, дожить и выйти в дверь с печатью о пяти гнёздах.
После финала игра показывает **настоящую карту** с линиями разломов и твоим путём.

## Управление

- `W A S D` / стрелки — движение (`S` — спиной вперёд, это единственный способ пройти квантовую дверь лицом к ней)
- мышь — взгляд (pointer lock; если браузер/iframe его запретил, включается свободный взгляд мышью)
- `Shift` — бег (Наблюдатели слышат и ускоряются)
- `M` — звук, `Esc` / `P` — пауза
- на тач-устройствах: джойстик слева, взгляд свайпом справа

## Устройство кода

```
index.html            разметка, HUD, экраны меню/паузы/финала
css/style.css         оформление: терминальный брутализм, виньетка, зерно, сканлайны
src/logic.js          ЧИСТАЯ логика: генерация мира, BFS/A*, валидация проходимости.
                      Не трогает DOM → тестируется в Node напрямую.
src/textures.js       процедурные текстуры и спрайты (canvas 2D → R/G/B/A-плоскости)
src/audio.js          WebAudio-синтез: дрон зон, шаги, дзвон осколков, гул дверей,
                      сердцебиение, шёпот, финальный аккорд. Ни одного семпла.
src/game.js           raycaster (DDA + floor casting + спрайты с z-буфером),
                      наблюдение/солидность, Наблюдатели, разломы, HUD, миникарта,
                      глитч-постобработка, адаптивное разрешение, экраны.
```

### Рендер

- DDA-raycast стен с текстурами и покадровым освещением: фонарик (конус + спад по
  дистанции), боковое затенение, экспоненциальный туман цвета зоны.
- Пол — полноценный floor casting; потолок — дешёвый градиент по строкам.
- Спрайты (осколки, разломы, Наблюдатели, руна выхода) — billboards с z-буфером и
  альфа-смешиванием; свечение дорисовывается аддитивными радиальными градиентами.
- Пост: глитч-слайсы и цветовой сдвиг при телепортах и поимках, CSS-виньетка/зерно/сканлайны.
- Внутреннее разрешение ~390×220 с пиксельным апскейлом; адаптивно падает/растёт по
  замеру времени кадра.

### Генерация мира

`recursive backtracker` + комнаты + «плетение» тупиков (петли) → 4 зоны многоисточневым
BFS → жадный разнос осколков → 5 пар разломов с поворотом → дверь выхода в дальнем
проходе → квантовые двери на стыках зон → Наблюдатели. Каждый кандидат валидируется
BFS-проходимостью; невалидный сид перегенерируется. Генерация детерминирована сидом.

## Тесты

- `tests/gen.test.js` — 63 мира: границы-стены, сущности на полу и не внахлёст,
  разломы далеко друг от друга, двери в проходах 1×1, A\*-пути непрерывны и без стен,
  детерминизм сида.
- `tests/game.test.js` — игра целиком в headless-DOM (свой стаб DOM/Canvas/WebAudio):
  старт, ходьба без NaN и застреваний в стенах, телепорт с поворотом и обратно,
  «дверь твёрдая под взглядом / проходимая без него» + проход спиной, подбор осколков,
  открытие выхода и честная карта, поимка Наблюдателем и замирание под взглядом,
  компас, финал, новая игра, пауза, 1000 кадров броуна, экстремальные пропорции окна.
- `tests/render.test.js` — настоящий растеризатор: гистограммы яркости кадров
  (читаемость/тени/контраст/без клиппинга), диапазоны текстур, прозрачность и яркие
  ядра спрайтов; сохраняет PNG-кадры через `--save=ПАПКА`.

`NE.debug` в `src/game.js` — небольшой отладочный доступ к состоянию, которым пользуются
тесты; полезен и при ручном ковырянии в консоли.
