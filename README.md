# ЧЕТВЁРТАЯ ОСЬ · 4D-лабиринт

Игра про пространство, которое не влезает в 3D.

Мир задан в четырёх координатах `(x, y, z, w)`. Ты живёшь в трёхмерном **срезе** `w`.
Стены существуют только в своём слое `w`:

* слой, в котором ты находишься — **твёрдый** (сплошной неон);
* остальные слои — **призраки**: их видно (они проходят через тебя и уходят в перспективу по `w`), но сквозь них нельзя пройти;
* нажатие `Q` / `E` сдвигает тебя по четвёртой оси — и стена, которая была перед тобой, перестаёт существовать.

Перспектива тоже четырёхмерная: чем дальше объект по `w`, тем сильнее он сжимается и тем ближе к центру кадра сходится. Это не «эффект», а честный 4D-конус.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | движение |
| мышь | обзор (клик — захват курсора) |
| `Q` / `E` | сдвиг по 4-й оси |
| `Shift` | ускорение |
| `R` | рестарт сектора |

На телефоне: стик слева — движение, свайп — обзор, кнопки `Q` / `E` — смена слоя.

## Что внутри

* 5 секторов, каждый — новая задача на 4D-мышление;
* три реальности одной комнаты (слои `-1`, `0`, `+1`), у каждой свой цвет;
* стражи, существующие только в своём слое; смена слоя = уклонение;
* осколки, спрятанные в разных слоях; в финале нужно собрать три;
* минимап показывает все слои сразу: ярко — твой, бледно — чужие;
* процедурный звук на WebAudio, «рябь реальности» при сдвиге.

## Запуск

Один файл, без зависимостей и сборки. Просто открой `index.html` в браузере.
Если хочется через сервер:

```bash
python3 -m http.server 8080
# затем http://localhost:8080
```

## Почему это не обычное 3D

Обычное 3D-движение — это три степени свободы. Здесь четвёртая ось не украшение: **она является частью правил**.
Лабиринт нельзя пройти в одном слое вообще — каждый сектор требует переключать реальность в правильной точке.
Плюс все уровни проверены поиском в графе состояний `(x, z, w)`, так что решения гарантированно существуют.

Сделано на Arena.ai.
