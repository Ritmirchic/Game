# ФАЙЛ

Один HTML-файл. Игра, которую нельзя пройти честно.

На второй минуте ты упрёшься в стену, которую физически невозможно перепрыгнуть.
И тогда игра покажет тебе **свой собственный исходный код** — и предложит его исправить.
Прямо во время игры. Ctrl+Enter — и физика меняется.

## Скачать

**Прямая ссылка:** https://github.com/Ritmirchic/Game/releases/latest/download/Game.zip

Распакуй и открой `game.html` двойным щелчком. Всё.

## Управление

| | |
|---|---|
| `←` `→` / `A` `D` | бег |
| `ПРОБЕЛ` / `W` / `↑` | прыжок |
| `R` | начать уровень заново |
| `M` | звук |
| `~` | **открыть исходный код игры** |
| `Ctrl+Enter` | применить правки |
| `F1` | вернуть оригинальный код |

## Что можно сломать

Весь исходник лежит внутри страницы в `<script id="SRC">` и выполняется через `eval`.
Редактор показывает **настоящий** код — тот самый, который сейчас работает.

```js
var GRAVITY = 0.62;   // поставь -0.62 — и потолок станет полом
var JUMP    = 11.2;   // высота прыжка = JUMP² / (2·GRAVITY)
var SPEED   = 3.4;    // скорость бега
var ENEMIES = 12;     // сколько врагов родится в «Лавине»
var GOD     = false;  // true — и смерть перестанет работать
var BOSS_HP = 8;      // сколько строк нужно удалить, чтобы убить Автора
var COLOR   = true;   // false — и мир станет чёрно-белым
```

Уровни — это ASCII-карты прямо в коде (`#` стена, `.` пустота, `^` шипы, `S` старт, `E` выход).
Сотри стену в карте — и её не станет.

Пять уровней: **ПЯТНО** → **СТЕНА** → **ПОТОЛОК** → **ЛАВИНА** → **АВТОР**.

## Технически

- Один файл, ~50 КБ, ноль зависимостей, работает офлайн из `file://`.
- Canvas 640×360, плитки 16 px, фиксированный шаг физики с подшагами.
- Оболочка (загрузка, редактор, сохранения, достижения) живёт **вне** перезапускаемого
  кода, поэтому сломанный `eval` не убивает игру: она продолжает работать на последней
  рабочей версии и показывает ошибку.
- Прогресс, смерти и достижения — в `localStorage`.
