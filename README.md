### 🧠 Что внутри — чем удивит

| Фаза | Время | Твист |
|------|-------|-------|
| **I — ОХОТА** | 0:00-1:00 | Собирай синие частицы, уворачивайся от охотников |
| **II — ГЛЮК** | 1:00-2:00 | Инверсия управления, гравитация, фейковые окна Windows, фейковый BSOD |
| **III — ПРИЗРАК** | 2:00-3:20 | Появляется твой призрак из будущего (экстраполяция вектора + курсора). Враги охотятся на НЕГО — научись их обманывать |
| **IV — ПЕТЛЯ** | 3:20-4:30 | Удерживай ПРОБЕЛ — отмотка времени. Твои клоны остаются и отвлекают врагов |
| **ФИНАЛ — ЗЕРКАЛО** | 4:30-5:00 | Тепловая карта твоих движений + психопортрет (ХИЩНИК / ИССЛЕДОВАТЕЛЬ / БЕРСЕРК / ПРИЗРАК) |

Фишки: параллакс-фон, частицы, trail, screen-shake, хроматика, процедурная музыка на Web Audio, анализ покрытия карты.

### 🎯 Управление
- **WASD / стрелки / мышь / тач** — движение
- **Клик / тап** — рывок
- **Пробел (удерж.)** — перемотка (с 3:20)
- **P** — пауза, **R** — рестарт в финале
