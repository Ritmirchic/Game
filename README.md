# МИРАЖ: Пепельный меридиан

Атмосферная браузерная 3D-выживалка с сюжетной кампанией в огромной открытой пустыне. Исследуйте бесшовные дюны, собирайте ресурсы, следите за водой, сражайтесь с хищниками и раскройте историю Меридиана.

Проект использует **Babylon.js 9 + TypeScript**, desktop- и mobile-управление. Текущий релиз — завершённый **первый этап расширения**: шесть связанных глав, шесть регионов, четыре многофазных босса и сохранение прогресса. Планы следующих этапов — в [`ROADMAP.md`](ROADMAP.md).

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Для слабого устройства в dev-версии можно добавить `?quality=low`.

## Один автономный HTML

```bash
npm run build && npm run build:html
```

Команда создаёт **`mirage.html`** в корне проекта. JavaScript, CSS, шрифты, favicon, GLB-модели, environment-карта и текстуры встраиваются в файл. Его можно открыть напрямую через `file://` **без сервера, интернета и внешних файлов**.

## Кампания

| Глава | Регион | Основные события |
| --- | --- | --- |
| I. Радиослед | Северный ретранслятор | Сбор ресурсов, ремонт вышки, первая оборона |
| II. Мёртвый караван | Пепельный тракт | Три грузовых контейнера и Альфа пепельной стаи |
| III. Сухой колодец | Соляные колодцы | Три водяных насоса, плевуны и Матка |
| IV. Погребённый город | Архив Тар-Су | Четыре архива, волны громил и удержание позиции |
| V. Грозовой разлом | Штормовое плато | Ускоренная жажда, Защитник Шпиля и длительная оборона |
| VI. Пепельный меридиан | Цитадель Меридиана | Архонт, запуск последнего ядра и финальная передача |

Переходы между главами сопровождаются диалогами. Каждая глава содержит несколько игровых шагов: путешествие, поиск и активация объектов, бой с боссом или удержание позиции. Это не отдельные меню уровней: все цели расположены в общем streamed-мире.

## Боссы и противники

- **Альфа пепельной стаи** — крупный вожак с бронёй и подкреплениями.
- **Матка сухого колодца** — дальние атаки и опасные зоны на земле.
- **Защитник Шпиля** — тяжёлый босс с усиливающимся преследованием.
- **Архонт Меридиана** — финальный трёхфазный противник.

На 66% и 33% здоровья боссы меняют фазу: ускоряются, усиливают атаки, вызывают стражу и чаще создают telegraph-зоны. До срабатывания такой зоны показывается красный маркер, из которого можно уйти или выскользнуть.

Обычные противники различаются поведением: преследователь, быстрый бегун, держащий дистанцию плевун и медленный громила. В регионах и во время оборон меняются состав волн, темп появления и число одновременных противников.

## Развитие и сохранение

- победы над главами улучшают копьё, sentry и броню;
- максимальное здоровье увеличивается до 115 и 130;
- броня снижает получаемый урон;
- удержания пополняют воду и ресурсы;
- в начале каждой главы создаётся контрольная точка в `localStorage`;
- кнопка **«Продолжить»** восстанавливает главу, снаряжение, ресурсы, фляги и статистику;
- после смерти кнопка **«Повторить главу»** загружает последнюю контрольную точку;
- после финала можно начать кампанию заново.

Сохранение выполняется на контрольных точках глав, а не после каждого отдельного действия.

## Открытый мир и графика

- детерминированный бесшовный рельеф без островной границы;
- потоковые чанки по **64 метра** с загрузкой и выгрузкой области вокруг игрока;
- длинные дюны, локальное понижение оазиса, колодцы, руины, скалы, кактусы, агавы и сухие деревья;
- шесть крупных сюжетных лендмарков: вышка, караван, соляная станция, погребённый город, штормовой шпиль и цитадель;
- фотографические PBR-текстуры, normal-map, environment lighting и ACES;
- динамические солнце, небо, туман, день/ночь и ветер с частицами песка;
- PCF-тени, bloom и FXAA;
- скелетные анимации Soldier и Fox, броня и фазовые аксессуары противников;
- трёхногие sentry с поворотной головой и трассерами;
- световая отметка цели и расстояние до неё в HUD.

На десктопе активна большая область потокового мира и более качественные тени. Сенсорный профиль и `?quality=low` уменьшают радиус загрузки, число декораций и разрешение теней.

## Игровые системы

- здоровье, выносливость, бег и гидратация;
- дневная жара ускоряет расход воды, ночь снижает температуру;
- фляги, колодцы и оазис;
- сбор обломков и волокна с сохранением добытых узлов при выгрузке чанков;
- направленный выпад копья с замахом, выносом вперёд и отдельной фазой контакта;
- скользящее уклонение с процедурной позой, пылью, затратой выносливости и короткой неуязвимостью;
- крафт до трёх автоматических sentry, каждая самостоятельно выбирает цель в радиусе 17 метров;
- перевязки, восстанавливающие здоровье;
- сюжетные диалоги, журнал текущей главы, полоса и фаза босса;
- победа, поражение, статистика и checkpoint-продолжение;
- SVG-интерфейс, полевой гайд, меню, HUD, пауза и сенсорные кнопки;
- процедурный звук через Web Audio.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | `WASD` / стрелки / левый сенсорный джойстик |
| Бег | `Shift` |
| Атака копьём | `F` или одиночный клик ЛКМ / сенсорная кнопка |
| Взаимодействие, сбор и активация | `E` / сенсорная кнопка |
| Скользящее уклонение | `Space` или `Q` / сенсорная кнопка |
| Выпить воду | `R` / кнопка фляги |
| Развернуть sentry | `1` — 8 обломков + 4 волокна |
| Перевязка | `2` — 3 волокна |
| Журнал текущей главы | `J` |
| Обзор | Перетаскивание ЛКМ или ПКМ / свайп по миру |
| Масштаб камеры | Колесо мыши |
| Пауза / закрыть диалог | `P` или `Escape` |

Кнопки крафта и фляги на HUD также работают мышью и касанием. На телефоне доступны отдельные кнопки атаки, действия, слайда и воды.

## Старая версия и ассеты

Завершённая игра **«ПОСЛЕДНИЙ МАЯК»** сохранена как автономный архив **`last-beacon.html`** и не перезаписывается сборщиком «МИРАЖА». Её игровые модули остаются в `src/game/` для справки и повторного использования моделей, материалов, эффектов и звука.

Все исходные файлы в `public/assets/` сохранены. Источники и лицензии перечислены в [`ASSETS.md`](ASSETS.md).

## Структура

```text
src/
  main.ts                 игровые коллбэки и сенсорное управление
  interface.ts            новый SVG-набор, меню, HUD и все экраны интерфейса
  desert.css              тактический GUI, кампания, боссы и адаптивные режимы
  desert/
    Campaign.ts           главы, диалоги, регионы, враги и типы кампании
    CampaignModels.ts     региональные лендмарки и интерактивные объекты
    DesertGame.ts         survival-цикл, кампания, AI, боссы и сохранения
    DesertWorld.ts        бесшовный streamed-мир, камера и среда
    DesertModels.ts       ресурсы, оазис, копьё, sentry и вышка
    types.ts              общие типы и UI-снимки
  game/                   сохранённые модули «Последнего маяка» и общие ассеты
public/assets/            локальные модели, текстуры и environment-карта
scripts/build-html.mjs    сборка автономного mirage.html
mirage.html               автономная текущая игра
last-beacon.html          автономный архив старой игры
ASSETS.md                 источники, авторы и лицензии
ROADMAP.md                следующие этапы расширения
```

Проверка проекта: `npm run build` выполняет строгую проверку TypeScript и собирает production-бандл.
