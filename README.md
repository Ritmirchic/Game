# НЕПОСТОЯННАЯ

Небольшая браузерная 3D-игра о прогулке по поверхности куба, где каждый край — переход на другую грань. Собери четыре эха на разных сторонах и найди открывшийся выход.

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```sh
python3 -m http.server 8000
```

## Управление

- `W A S D` или стрелки — шаг по текущей грани; на краю персонаж переходит на соседнюю сторону куба.
- `Q` / `E` — поворот пространства.
- `R` — начать заново.
- `M` — звук.

Игра сделана на Canvas 2D без игровых движков: 3D-куб и его грани проецируются и рисуются вручную.
