# ЭХО

Атмосферная браузерная головоломка на 3–5 минут. Петля времени записывает каждую попытку: прошлые версии игрока повторяют пройденный путь, удерживают пластины и открывают дорогу вперёд.

В финале траектории всех попыток превращаются в персональное созвездие. Его можно сохранить как PNG — рисунок зависит от реальных движений игрока.

## Скачать одним HTML-файлом

**[Скачать `echo.html` с GitHub](https://github.com/Ritmirchic/Game/raw/refs/heads/arena/25a7d963-game/echo.html)**

Автономная версия содержит код, стили и шрифты внутри одного файла. Скачай её и открой в современном браузере двойным кликом — установка и сервер не нужны. Эта же ссылка находится на финальном экране игры.

Чтобы самостоятельно пересобрать автономный файл:

```bash
npm install
npm run build:single
```

Готовый файл появится в корне проекта как `echo.html`.

## Запуск для разработки

```bash
npm install
npm run dev
```

Vite поднимет локальный сервер. Для production-сборки:

```bash
npm run build
npm run preview
```

## Управление

- **WASD / стрелки** — движение.
- **Удерживание мыши или пальца на поле** — движение к точке касания.
- **Пробел / «Оставить эхо»** — завершить текущий цикл, сохранить записанный путь и вернуться в начало.
- **Esc** — пауза.
- **M** — включить или выключить звук.

Смертей и проигрышей нет. Если решение не получилось, новый цикл становится частью головоломки. Через меню паузы можно заново начать текущую главу.

## Проверки

```bash
npm test
npm run build
```

Тесты покрывают воспроизведение записей, пластины, одновременное открытие дверей, защиту от закрытия двери на игроке, столкновения и детерминированную генерацию созвездия.

## Технически

Проект использует Vanilla JavaScript, Canvas 2D, Web Audio API и Vite. Визуальные эффекты, анимации и звук генерируются кодом; внешние изображения и аудиофайлы не нужны. Шрифты Manrope и Unbounded поставляются локально через Fontsource.

- `src/main.js` — игровой цикл, ввод, состояния и Canvas-рендеринг.
- `src/levels.js` — три главы и их геометрия.
- `src/logic.js` — чистые правила движения, записей и взаимодействий.
- `src/audio.js` — генеративный эмбиент и звуковые сигналы.
- `src/constellation.js` — преобразование реальных траекторий в финальное небо.
- `src/style.css` — адаптивный интерфейс и переходы.
