# ВНУТРИ БЕСКОНЕЧНОСТИ

3D-игра, в которой **нет ни одного полигона**.

Мир здесь не нарисован — он *вычисляется*. Каждый пиксель экрана отправляет луч
в бесконечную самоподобную структуру (аполлониево складывание пространства:
`p → −1 + 2·fract(p/2 + 0.5)`, затем инверсия радиуса на каждой из 5 итераций).
То, что вы видите, — не модель, а решения уравнения, посчитанные на видеокарте
в реальном времени: реймарчинг, нормали, AO, мягкие тени, отражения и звёздное небо.

## Как играть

Откройте `index.html` в браузере (WebGL). Один файл, без библиотек и без сети.

| Клавиши | Действие |
|---|---|
| `W A S D` | плыть |
| мышь | смотреть (клик — захват; работает и перетаскивание) |
| `← →` / `Q E` | поворот без мыши |
| `SPACE` / `C` | вверх / вниз |
| `SHIFT` | рывок |
| `F` | полный экран |

Соберите **7 ядер** — стрелка в центре показывает на ближайшее.
После седьмого начнётся бесконечный зум внутрь структуры.

## Что внутри

- **Фрактальная функция расстояния** в фрагментном шейдере (WebGL 1, GLSL ES 1.0) —
  ни вершин, ни текстур, ни загружаемых ассетов.
- **Столкновения** считаются той же формулой на CPU (JS-двойник поля расстояний),
  выталкиванием по градиенту — поэтому «стены» можно нащупать, но нельзя пробить.
- **Звук синтезируется** через WebAudio: расстроенные дроны, шум скорости,
  аккорды при сборе ядра. Ни одного аудиофайла.
- **Адаптивное разрешение**: если GPU не справляется, картинка сама снижает
  внутреннее разрешение, сохраняя отзывчивость.
