# ASHES OF HUMANITY: LAST SIGNAL

Grounded post-apocalyptic survival horror Roblox place (`ASHES_OF_HUMANITY.rbxl`) built with a server-authoritative `--!strict` Luau architecture, 6 connected surface regions + Underground Emergency Shelter Echo-07, 10 distinct mutant AI species, 6-region anatomical trauma & survival coupling, spatial grid inventory, workstation crafting, base fortification, and a 6-act main storyline.

## Direct `.rbxl` Download
- **Direct Download (`ASHES_OF_HUMANITY.rbxl`)**: <https://github.com/Ritmirchic/Game/raw/arena/64fbbc9f-game/ASHES_OF_HUMANITY.rbxl>

## Opening in Roblox Studio
1. Download `ASHES_OF_HUMANITY.rbxl` and open it directly in **Roblox Studio** (`File -> Open from File...`).
2. Press **Play (F5)** to spawn immediately inside **Underground Emergency Shelter Echo-07** with your starter survival kit (`DamagedFlashlight`, `SmallBackpack`, `PipeClub`, `OldFieldRadio`, `HalfCanteen`, `StaleRationBar`, `RagBandage`, `Echo07Note`).
3. Optional for cloud `DataStoreService` outside local Studio session fallback: publish the experience and enable **Game Settings -> Security -> Enable Studio Access to API Services**.
4. Optional custom PBR & Mesh import: 56 procedural 512x512 PBR maps (`assets/textures/`) and 41 Blender 5.0 low-poly `.obj` meshes (`assets/meshes/`) are included in the repository for batch upload via Roblox Studio **Asset Manager**.

## Controls (Desktop + Touch Action Bar Supported)
- **Move / Sprint / Jump**: `WASD` / `Left Shift` / `Space`
- **Crouch / Prone Crawl**: `C` / `Z`
- **Vault Low Obstacles**: `Space` near 1.8–4.6 stud ledges/windows
- **Fire / Melee Attack**: `Left Mouse Button`
- **Aim Down Sights (ADS)**: `Right Mouse Button`
- **Reload Firearm**: `R`
- **Toggle Flashlight**: `F`
- **Interact / Loot / Read Lore / Revive Teammate**: `E`
- **Toggle Camera (1st-Person / Over-Shoulder 3rd-Person)**: `V`
- **Inventory & Equipment Grid**: `Tab` or `I`
- **Medical Body-Region Trauma Panel**: `H`
- **Crafting & Workstations**: `K`
- **Mission & Lore Archive**: `J`
- **Co-op Survivor Squad**: `P`
- **Base Building Mode / Rotate / Cycle Blueprint**: `B` / `T` / `[` and `]`
- **Graphics & Accessibility Settings**: `M`
- **Weapon Slots & Quick Hotbar**: `1`–`3` (Primary/Secondary/Melee), `4`–`8` (Hotbar)
