# Anvilight — кнайт-храм · зацикленная анимация для рабочего стола

Референс: `src/reference.png` (1376×768) — единственный источник, сам кадр не перерисовывался
и не «перегенерялся», из него получены все кадры.

## Что внутри

| Файл | Что это |
| --- | --- |
| `keyframes/frame_01.jpg` … `frame_10.jpg` | 10 кадров, 3840×2160 (16:9), JPEG q97 |
| `keyframes/contact_sheet.jpg` | сетка всех 10 кадров для быстрого просмотра |
| `video/anvilight_knight_loop_4k.mp4` | основной луп: 3840×2160, 30 fps, 10 c, H.264 yuv420p, без звука |
| `video/anvilight_knight_loop_10frames.mp4` | те же 10 кадров, соединённые напрямую (5 fps, 2 c) |
| `stills/wallpaper_3840x2160.png` | обои 4K, кадр на вершине «вдоха» |
| `stills/wallpaper_7680x8640.jpg` | 16K (15360×8640), JPEG q2, ~19 МБ — практичный 16K-файл |

Оба видео зациклены бесшовно: кадр 0 = кадр N по состоянию, поэтому повтор без рывка.

## Анимация

Одна фаза `e ∈ [0..1]`, косинусное сглаживание: 0 → 1 за первую половину лупа,
1 → 0 за вторую. На кадре 1 (и 10) — нижняя точка и самый тёмный кадр,
на кадре 6 — верхняя точка и самый светлый.

* **Подъём/опускание**: персонаж смещается вверх на 16 px (в координатах референса ≈ 45 px в 4K).
  Смещение делается плотным полем деформации с весами-«каплями» вокруг шлема, торса,
  наплечника, клинка и горящей руки. Архитектура собора остаётся на месте, швов и «дыр» нет.
* **Дополнительное покачивание**: ±5 px по горизонтали, ноль на вершине, разные знаки
  на подъёме и спуске — поэтому все 10 ключевых кадров различимы, а не дублируются.
* **Тише и светлее**: экспозиция +10 %, тени открываются (+1.6 % к чёрному), насыщенность −9 %,
  мягче bloom (0.15 → 0.22), красный свет клинка и руки пульсирует чуть сильнее камня.
* Зерно и дизеринг добавлены, чтобы на тёмных градиентах не было полос (banding).

## Пересборка

```bash
python3 -m venv ../.venv && ../.venv/bin/pip install pillow numpy opencv-python-headless imageio-ffmpeg
cd wallpaper
../.venv/bin/python build.py keyframes   # 10 кадров + контактный лист
../.venv/bin/python build.py video        # mp4-лупы
../.venv/bin/python build.py stills       # 4K / 8K обои
../.venv/bin/python stills_16k.py         # 16K (тайлами, чтобы влезть в память)
```

Все параметры движения и света — константы в начале `build.py`:
`RISE_PX`, `SWAY_PX`, `BRIGHT_MAX`, `SHADOW_LIFT`, `SAT_SOFTEN`, `BLOOM_*`.

## Заметки по реализации

* `cv2.remap` в этой сборке OpenCV отдаёт NaN на повторных вызовах с float-картами,
  поэтому деформация считается явным билинейным gather в numpy — детерминированно.
* 16K собирается из 8K-мастера полосами по 540 строк и стримится в ffmpeg:
  один кадр 16K в float32 — это ~1.6 ГБ, в 4 ГБ памяти целиком не проходит.
* `stills/wallpaper_15360x8640.png` (263 МБ) в git не кладётся из-за размера;
  16K-JPEG выше — тот же кадр, различия ниже порога восприятия.
